# Mark Up - Student Grading Portal

A secure, database-driven web portal designed to manage and display student academic grades using individual student credentials (username and password).

## Technologies Used
* **Backend:** PHP
* **Database:** MySQL / SQL
* **Frontend:** HTML5, CSS3
* **Desktop Integration:** Java / JavaFX

## Key Features
* **Secure Authentication:** Role-based login system protecting student records.
* **Student Grade Portal:** Clean interface allowing students to view their grades securely.
* **Database Management:** Structured relational database using MySQL for fast and reliable data retrieval.
